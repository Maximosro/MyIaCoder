Getting started

Three steps to your AI command center

01

Install

Download the installer, run it, and Focusxide sets up in seconds. Requires Windows 10+ and Node.js 18+.

winget install Focusxide
02

Add your projects

Point Focusxide to your project folders. The sidebar populates instantly — drag, drop, and organize your workspace.

Ctrl+O → Select folder → Ready
03

Start coding with AI

Open terminals for Claude Code, Copilot, or any AI CLI. Code, edit files, review diffs — all without leaving the app.

New Tab → Choose AI → Code

FAQ

Questions you might have

Focusxide works with any terminal-based AI coding tool. Out of the box, it supports Claude Code, GitHub Copilot (CLI), CodeWhale, Reasonix, and OpenCode. You can also add any custom terminal command — if it runs in a terminal, it runs in Focusxide.

Yes. Focusxide is MIT licensed — completely free, no strings attached. No subscriptions, no telemetry, no accounts required. The source code is available on GitHub. You're free to use it, modify it, and contribute back.

Currently, Focusxide is Windows-only. It's packaged as an NSIS installer (.exe) via electron-builder. The underlying stack (Electron, React, node-pty) is cross-platform, so macOS and Linux support is technically possible — contributions welcome!

VS Code's terminal is general-purpose. Focusxide is purpose-built for AI coding workflows: it manages multiple AI CLI sessions in parallel, tracks tasks and plans generated by AI, and shows git changes in a dedicated panel. It's not an editor — it's a command center for AI-assisted development.
